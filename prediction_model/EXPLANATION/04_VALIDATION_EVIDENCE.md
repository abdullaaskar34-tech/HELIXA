## 3. Does the model still identify the right subtype?

| | v1 | v2 in-sample | v2 leave-one-out |
|---|---|---|---|
| all 328 | 98.17% | 97.87% | **97.87%** |
| CORE (n=273) | 100.00% | 99.63% | **99.63%** |
| BOUNDARY (n=55) | 89.09% | 89.09% | **89.09%** |

In-sample and leave-one-out are identical, which says the model is not
overfitting — removing any single patient does not change the answer for that
patient.

The 7 in-sample disagreements are patients whose consensus profile itself
points somewhere other than the agglomerative label they were assigned: 1 CORE
and 6 BOUNDARY tumours. They are genuinely intermediate cases, not model
failures. `predict.py` reports the recorded assignment for any sample in the
training cohort alongside the model's independent read, so a round trip on a
known patient always returns that patient's recorded subtype.

## 4. Does the percentage mean what it claims?

Measured out-of-fold — i.e. on patients the model did not see during fitting,
which is the situation a brand-new patient is in:

| | value |
|---|---|
| correlation, predicted vs true consensus (all 328 × 6 cells) | **+0.9656** |
| RMSE over all cells | 0.0766 |
| mean absolute error on the top class | **0.1130** |
| correlation, top-class probability vs its consensus share | +0.7486 |

So when the model reports 73%, the consensus clustering's own figure for that
patient and subtype is typically 73% ± 11. The full six-way shape is captured
well (r = 0.966); the top-class magnitude is noisier (r = 0.749), and
`07_...` is explicit about what that means in practice.

## 5. Model family comparison

Twelve candidates, all scored out-of-fold against the consensus profile. The
plain linear model won; every more flexible alternative was worse. Full table in
`03_HOW_THE_NEW_MODEL_WORKS.md`. This says the remaining error is irreducible
given 5 principal components, not a failure to fit.

## 8. The protocol detector

327 / 328 = **99.695%**, not the 100% claimed in the v1 docstring. The poly(A)
and total-RNA non-polyA fractions overlap (poly(A) max 0.21736, total-RNA min
0.10354), so no single threshold can do better. For the one misdetected sample
the downstream probability shifts by 0.29.
